### About

I'm a frontend engineer and full stack developer. I care about the parts of a product most people don't notice — the easing on a modal, the spacing between elements, the way a page loads. That attention to detail carries through to everything I build, from the UI layer down to the API and database.

Currently going deep on Three.js, WebGL, and building AI-powered tools. I think the next generation of interfaces will be 3D and generative, and I want to be building them.
